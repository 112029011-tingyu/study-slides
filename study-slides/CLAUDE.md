# 課程重點簡報站 (study-slides)

## 1. 專案目的
把英文為主、動輒 100 頁以上的課程 PPT,濃縮成中文重點簡報,讓我在考前 1~2 小時內複習完一週內容。
我只會提供講義 PDF 並說「整理【科目】第 N 週」,AI 就應產出符合本文件的簡報頁面。

## 2. 技術限制
- 純 HTML + CSS;JavaScript 僅限 `js/slides.js`(翻頁)
- 不使用框架、CDN、build 工具;必須能直接部署在 GitHub Pages
- 所有路徑使用相對路徑
- 禁止 inline style,樣式只寫在 `css/slides.css`

## 3. 檔案結構與命名
- 簡報:`subjects/<科目英文>/week-XX-<主題>.html`,例:`subjects/machine-learning/week-03-overfitting.html`
- 科目資料夾小寫英文、連字號;週次固定兩位數
- 新簡報一律複製 `subjects/_template.html`
- 原始講義放 `source/`,**不得上傳 GitHub**(已列入 `.gitignore`)

## 4. 視覺風格
- 氛圍:乾淨、專注、適合螢幕閱讀
- 主色 `#2563eb`,背景 `#f8fafc`,文字 `#1e293b`,重點標記 `#f59e0b`
- 字體:"Noto Sans TC"(系統字體備援),程式碼用等寬字體
- 一張投影片 = 一個 `<section class="slide">`
- 每張投影片最多 5 個條列,每條不超過 30 字(英文術語除外)

## 5. 濃縮規則(最重要)
- 每 10 頁原始 PPT 約對應 1 張投影片;100 頁產出 10~15 張,不超過 20 張
- 保留:定義、公式、比較、步驟、老師強調的內容、範例結論
- 刪除:封面、目錄、重複內容、純裝飾圖、參考文獻頁
- 說明用繁體中文;專有名詞保留英文並附中文,格式:「過擬合 (Overfitting)」
- 每張投影片標註來源頁碼:`<span class="source">原 PPT p.23–30</span>`

## 6. 簡報固定結構(順序固定)
1. 封面(`class="slide cover"`)
2. 本週學習目標(3~5 點)
3. 核心概念(數張,`class="slide concept"`)
4. 比較表(若內容可比較)
5. 術語表:English / 中文 / 一句話解釋
6. 考前必背(`class="slide must-know"`,最多 7 點)
7. 自我測驗:3~5 題,答案用 `<details>` 收合,並附返回目錄連結(`class="slide quiz"`)

## 7. 新增週次的標準流程
1. 讀本文件與 `subjects/_template.html`
2. 讀講義,先列出「章節 → 頁碼範圍」大綱給我確認
3. 我確認後,複製範本並依第 5、6 節產出簡報
4. 更新 `index.html` 目錄(依科目分組、週次由小到大)
5. 回報:新增/修改的檔案、投影片張數、不確定的內容

## 8. AI 行為規則
✅ 必須做
- 每個重點都能對回原始頁碼
- 公式、數字、定義照講義,不改變意思
- 看不清楚或不確定的內容標註「(待確認)」
- 圖表無法重現時,用文字描述並標註頁碼

❌ 不可做
- 不可補充講義沒有的內容並當作講義內容
- 不可編造公式、數據、引用文獻
- 不可修改既有簡報的版型與樣式
- 不可把原始 PPT/PDF 或整頁截圖放進 repo
- 不可更動命名規則
